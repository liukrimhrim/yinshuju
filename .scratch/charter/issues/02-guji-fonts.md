# 开源古籍字体与授权

Type: research
Status: resolved

## Question

用哪些字体能在 web 上还原样张气质且授权干净？盘点候选（至少覆盖：汇文明朝体、京华老宋体、全字库正楷体/隶书体、思源宋体、Noto Serif TC，以及样张里出现的「国文正楷 Kai Oldstyle」与康熙字典体的授权真相）。每款给出：授权证据链接（一手来源，不得凭记忆）、字符覆盖（繁体 + 常用异体字）、与样张气质的匹配度、文件体积与 web 子集化/切片方案（fonttools / unicode-range 分片）。印章用篆书字体归「印章生成方案」票，此票只管正文/夹注/标题。结论给一个推荐组合。

## Answer

详见 [研究文档](../research/02-guji-fonts.md)（全部授权结论带证据链接）。

**推荐组合**：正文 = 汇文明朝体（铅印刻本味最浓，台标繁体全收，修正版仓库 CC0，TTF 23.7MB）；夹注/生僻字兜底 = 全字库正楷体 TW-Kai（可选 OFL 1.1，繁体 97,681 字）；标题 = 京华老宋体（整包用）或汇文加大；UI/终极兜底 = Noto Serif TC（OFL）。

**授权结论**：汇文明朝体/京华老宋体 = 作者声明免费商用（原始声明页被反爬，条款转录自猫啃网，**非一手，已如实标注**）；全字库 = 政府开放授权 v1 或 OFL 1.1 二选一（data.gov.tw 一手确证）；思源宋体/Noto Serif TC = OFL 1.1（一手确证）；I.Ming = IPA v1.0（衍生再分发义务较重）。

**排除项**：康熙字典体（版权已卖断，无公开许可证）；样张里的国文正楷 Kai Oldstyle（左佐 zuotype 商业零售字体，web 嵌入授权未能核实）；天珩全字库（字形来源不洁）；上图东观体（限非盈利）。勘误：全字库无「隶书体」。

**子集化**：主方案 = unicode-range 切片自托管（cn-font-split，100+ 片，省 ~90% 流量）；固定 UI 文案用 pyftsubset 静态预子集。**注意京华老宋体「禁改字体」条款与切片/子集冲突**——只整包用于标题，或去信作者求许可。

**导出注意**：Canvas 画 PNG 前必须 `await document.fonts.load`；PDF 用 pdf-lib+fontkit（jsPDF 不吃 OTF，思源是 OTF）；OFL 自用子集嵌入无碍，提供字体下载才触发 RFN 改名义务。
