# 开源古籍字体与授权

Type: research

## Question

用哪些字体能在 web 上还原样张气质且授权干净？盘点候选（至少覆盖：汇文明朝体、京华老宋体、全字库正楷体/隶书体、思源宋体、Noto Serif TC，以及样张里出现的「国文正楷 Kai Oldstyle」与康熙字典体的授权真相）。每款给出：授权证据链接（一手来源，不得凭记忆）、字符覆盖（繁体 + 常用异体字）、与样张气质的匹配度、文件体积与 web 子集化/切片方案（fonttools / unicode-range 分片）。印章用篆书字体归「印章生成方案」票，此票只管正文/夹注/标题。结论给一个推荐组合。
