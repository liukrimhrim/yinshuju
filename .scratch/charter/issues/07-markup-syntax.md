# 输入标记语法

Type: grilling
Status: resolved
Blocked by: 01

## Question

用户输入到底长什么样？定一个轻量标记语法：正文 / 夹注（双行小字）/ 书名·卷次·作者 / 手动句读点（自动句读不靠谱时的降级）各怎么表达；要不要兼容 markdown；粘贴纯文本时的零标记体验是什么。产出：语法 v1 规范 + 用样张原文写的 3 个真实样例。

## Answer

四个分叉全部按推荐定案（用户拍板）：**元数据走 UI 表单不进正文**（书名/卷次/著者渲染进固定槽位）；**圆括号=夹注**（全半角均认，双行小字）；**现代标点自动映射句读**（。！？→句○，，、；：→读丶，其余丢弃，可整体关闭；点选 UI 日后即增删标点字符，数据模型零新增）；**结构只认空行=提行、#=篇题**，其余 markdown 不解析。

产出：[docs/markup-v1.md](../../../docs/markup-v1.md)（规范 + 解析模型 + 取自三张样张原文的样例：鬼谷子/香乘/道德经——香乘的「梅花香（一）」序号恰好天然落进夹注语法）；域模型种子 [domain.md](../../../domain.md)。旁注/眉批明确留到 v1 之后，语法留扩展位。
