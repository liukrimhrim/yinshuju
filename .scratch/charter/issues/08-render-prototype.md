# 渲染路线样张验证

Type: prototype
Blocked by: 02, 03, 04

## Question

用鬼谷子样张（或《香乘》）的真实文字，按「竖排渲染与导出技术路线」的推荐做一页穷人版渲染：竖排 + 版框界行 + 双行夹注 + 一枚印章 + 导出一张高清 PNG。验证：排版保真度、导出保真度、代码量级。推荐路线若翻车，换备选路线再试一轮。产出：可跑的 demo + 定案的技术路线。

注（来自「先行项目与可借力库」）：验证时必须附带试一次打印 PDF——竖排分页是全图最大技术风险（Firefox 有竖排只打一页的历史 bug）；渲染部分可对标 vRain 的版式参数体系，分页可先试 nehan。
