# 渲染路线样张验证

Type: prototype
Status: resolved
Blocked by: 02, 03, 04

## Question

用鬼谷子样张（或《香乘》）的真实文字，按「竖排渲染与导出技术路线」的推荐做一页穷人版渲染：竖排 + 版框界行 + 双行夹注 + 一枚印章 + 导出一张高清 PNG。验证：排版保真度、导出保真度、代码量级。推荐路线若翻车，换备选路线再试一轮。产出：可跑的 demo + 定案的技术路线。

注（来自「先行项目与可借力库」）：验证时必须附带试一次打印 PDF——竖排分页是全图最大技术风险（Firefox 有竖排只打一页的历史 bug）；渲染部分可对标 vRain 的版式参数体系，分页可先试 nehan。

## Answer

**路线定案：自研布局引擎（网格→逐字坐标表）→ SVG per-char 渲染，三出口共用坐标数据。** 原型在 `proto/render-route` 分支（运行 `proto/run.sh`），四轮迭代全部验证通过：

1. **版式机器**：竖排网格、双行夹注（JLREQ 均分/右行先/注毕回单行）、句读圈点（右下不占字位）、版心（折缝半列：半鱼尾+半字，左框开口）、左右双边版框、白文印。布局+渲染+双导出约 300 行 JS，运行时零依赖（pdf-lib 仅导出时用）。
2. **导出**：PNG = SVG(内嵌 data-URI 字体)→canvas ×3（1920×3360，清雅主题 0.7MB/1.2s，做旧主题 9.9MB/1.6s——噪声纹理压缩差，后续可调）；PDF = pdf-lib 16×28cm 精确尺寸（2.8–6.2s）。
3. **用户两轮反馈驱动的能力验证**：字面率提到 ~85%、满页密排；字体 A/B（汇文明朝/朱雀仿宋切换，两款子集分别 168KB/64KB，机制=任意字体可换）；主题系统（鬼谷子·清雅 / 香乘·做旧两组全参数配色）；**纸墨纹理纯 SVG 滤镜实现且完整通过导出管线**（feTurbulence 纸斑+墨蚀+框损）。
4. **意外红利**：标记语法票的「现代标点→圈点」决策使刻本视图不渲染任何标点字符——竖排标点形（原风险#2）在 v1 消失。

**采下的产品需求**（转入后续票）：颜色可定制（→视觉主题票）、字体可自定义+默认延后（→视觉主题票/MVP 票）、纹理逼真度继续打磨（→视觉主题票）。

**遗留风险**（实现阶段首验）：Safari 的 SVG-as-image 内嵌字体未实测（本环境 Chromium；text→path 兜底已在路线中）；多页 PDF 未演练（分页纯算术，风险低）；做旧滤镜参数为初版。
