# 视觉主题定案

Type: grilling
Status: resolved
Blocked by: 08

## Question

首发主题集定案。候选（源自样张）：清雅素白（鬼谷子蓝）、仿古做旧（香乘）、朱印本（通体朱墨）、朱丝栏（红框黑字 + 圈点）。定：每主题的参数化要素（纸色/纸纹理/框色/正文色/夹注色/印色）、首发几个、默认哪个、做旧纹理素材的来源与授权。

补充（来自样张验证票的用户需求，2026-07-31）：本票必须覆盖——做旧滤镜参数打磨（纸纹/墨蚀/框损强度、夹注小字的易读性）；「逼真还原纸墨纹理」是明确验收标准（对标《香乘》样张）；颜色自定义暴露到什么程度（引擎已全参数化）；每主题默认字体（字体须用户可选，原型已带汇文明朝/朱雀仿宋双子集）。原型 `proto/render-route` 分支可直接当调参台。

补充（vRain 研读，2026-07-31）：主题候选可加「竹简」彩蛋；版心标题可选「书名+章回数字」自动后缀（vRain 的 X 替换机制）。

## Answer

用户拍板：**首发四主题全上**（朱丝栏/清雅素白/仿古做旧/朱印本，各对应一张样张）；**默认主题=朱丝栏**；**字体按主题配出厂默认**（做旧=汇文明朝，其余=朱雀仿宋；始终可改）；**颜色七参数（纸/正文/夹注/圈点/框/界行/印）逐色可调**，主题只是预设起点。

做旧纹理定案：纯程序化 SVG 滤镜（零素材零授权、seed=内容哈希可复现）、强度滑杆、夹注小字侵蚀减档（易读性守则）、验收对标《香乘》样张。版心新增可选"当前篇题自动入版心"。竹简/磁青列后续候选。

产出：[docs/themes-v1.md](../../../docs/themes-v1.md)（含完整参数表，可直接落成引擎主题配置）。
