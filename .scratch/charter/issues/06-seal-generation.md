# 印章生成方案

Type: research
Status: resolved

## Question

如何在前端生成样张里那种印章？免费可商用的篆书字体盘点（授权证据一手链接）、SVG 生成方印/圆印/椭圆印的先例（有无现成库）、朱文（阳刻）与白文（阴刻）各自的实现法、边缘做旧（残缺/斑驳）的技法。输出推荐路线，供后续印章功能票使用。

## Answer

详见 [研究文档](../research/06-seal-generation.md)。

**篆书字体**：首选**全字库说文解字字型**（说文小篆 6721 字，政府資料開放授權條款 v1，允许商用+改作/子集化，与 CC-BY 4.0 相容，须显名；一手证据 cns11643.gov.tw + data.gov.tw/license）。崇羲篆体 CC-BY-ND（禁改作、不能子集化）仅候补；峄山碑篆体的"免费商用"仅猫啃网转述、一手声明未核实；方正/汉仪篆书均商业；「缪篆/摹印篆」无任何开源实现；所谓「全字库篆体」不存在。

**生成技法**：无现成前端 SVG 藏书印轮子，自研量小。opentype.js 转 path → SVG 组装；朱文 = 红框+红字；白文 = 红底 rect + mask 挖空（保纸纹）；做旧 = feTurbulence+feDisplacementMap 扭边 + 阈值噪声打斑（seed 取印文哈希，同印同貌）；印泥感 = 径向渐变+噪声 alpha+multiply 叠纸。范式可照抄 vYinn（MIT，古籍印章专用）与 DrawStampUtils（Apache-2.0，毛边/做旧参数）。

**缺字降级**（有史据：宋楷书官印、明清隶楷藏书印）：任一字缺篆即**整印退楷**（全字库正楷体，同源同授权），不混排。

**后记（来自「开源古籍字体与授权」票）**：字体调研发现说文篆体 ttf 下载页另标「个人与系统发展使用」，与本票「政府开放授权可商用」的结论冲突。印章功能开工前必须复核一手条款，两说取其实。
