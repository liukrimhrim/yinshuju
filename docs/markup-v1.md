# 印书局输入格式 v1

定案于「输入标记语法」票（2026-07-31）。原则：**粘贴纯文本（含现代标点）零标记即出可看版面**；需要学的标记只有两条（括号、#），外加空行习惯。

## 规则

0. **空行**：段间一个空行＝提行（起新列），**每多一个空行＝再空一列**；**正文开头的空行**无段可分，故每个都空一列——用于在著者列与正文之间留空列。
1. **空格留白**：半角空格＝**半字位**、全角空格「　」＝**一字位**，可连用（抬头空二字、句间停顿等）。正文、篇题行、题署行、书名/著者栏一律适用。
1. **段首 `[天,地]`**＝**该段留白**（半角方括号）：`[2]` 天地各留 2 字位、`[2,0]` 只留天头、`[0,3]` 只留地脚，支持 0.5 步进。仅对该段生效，覆盖版式面板的全局留白，段末自动复原。
1. **行内字号是相对值**：`*小*`／`**大**` 的倍率**相对所在列的基准字号**（正文 1×、篇题／书名／著者各有滑杆、夹注为半字号）。故同一个 `*小*` 在篇题列与题署列的实际大小会因基准不同而不同——把两列的基准调成一致即可齐平。
1. **行内标记通用**：字号（`*小*`/`**大**`）与旁线在**篇题行、题署行**同样生效（标记符本身不入字）。**书名／著者栏**同样走这一套（字号、夹注、句读、旁线一致）。**版心简名／卷次栏**受版心窄列所限，只识别字号标记（`*` 0.8×、`**` 1.35×，相对版心常规字），星号同样不入字。
1. **`#`／`>` 行的留白**：版式面板可调「篇题低格」「题署距底」（默认各 2 字位）；行内加 `[n]` 可单独覆盖，如 `# [0]靜夜思`（顶格）、`> [0]唐李白撰`（贴底）。
1. **`>` 行**＝**题署**：该行自成一列，与卷端著者同样**低格对齐**（末尾留两字位）、同一字号倍率。可多次使用——数位作者的作品因此能并列于同一对开叶。
1. **`---` 行**（三个及以上连字符独占一行）＝**分叶符**：其后文字另起一叶。连续分叶符或开头即分叶不会产出空叶。
1. **元数据不进正文**。书名、卷次、著者（、日后的印章内容）是 UI 表单字段。渲染槽位：首行顶格「书名+卷次」、次行低格著者、版心书名+页码（槽位规则见版式规范研究文档）。正文框里只有正文。
1. **圆括号 = 夹注**。半角 `(…)` 与全角 `（…）` 均认，括号内文字渲染为双行小字夹注（半字号、右行先、偶数均分奇数右行多一字、注毕回单行——JLREQ 割注规则）。夹注紧跟被注文字书写，不可嵌套。注内标点按第 3 条同样映射（小号圈点）。
1. **现代标点 → 句读圈点**。`。！？` → 句（小圈 ○）；`，、；：` → 读（点 丶）；渲染于前字右下角、**不占字位**。引号、书名号、省略号、破折号等其余标点静默丢弃。文档级开关可全部隐藏（无句读的素刻本样）。无标点的古文粘进来自然无圈点。日后的"点选句读 UI"= 在预览上增删这些标点字符，数据模型零新增。
1. **结构只认两条**：空行 = 段落提行（起新列）；`#` 开头的行 = 篇题（自成一列，样式别于正文；日后可联动版心/书耳）。其余 markdown 一律不解析。

## 边界情形

- 原文含括号序号如「梅花香（一）」→ 按夹注渲染成小字——与样张《香乘》的实际排法恰好一致，不是 bug 是 feature。
- 单独短行不做"猜标题"的魔法；是篇题就加 `#`。
- 简体输入：先句读映射、再 s2t、后旧字形（管线顺序见文本管线票）；括号与 `#` 不受转换影响。

## 解析模型（实现参考）

```
Document  = { meta: {title, juan, author}, blocks: Block[] }
Block     = { type: 'chapter' | 'para', runs: Run[] }   // 按空行切块；#行 → chapter
Run       = { t: 'text', s }                            // 正文字符串
          | { t: 'note', s }                            // 夹注（括号内）
          | { t: 'punct', kind: 'ju' | 'dou' }          // 句/读，附着于前一字符
```

## v2 增补：旁线标记（2026-08-01）

全角括对标出跨字旁线，画在字右侧、不占字位（源自 vRain 体系）：

| 写法    | 渲染           | 用途                |
| ------- | -------------- | ------------------- |
| `《…》` | 波浪线（墨色） | 书名号              |
| `［…］` | 直线（墨色）   | 专名号（人名/地名） |
| `｛…｝` | 小圈（批点色） | 着重圈注            |
| `＜…＞` | 小点（批点色） | 着重点注            |

半角 `<>` `[]` `{}` 仍按 v1 静默丢弃，不与本语法冲突；标记内的标点照常映射句读；未闭合吃到块尾。

## v2 增补：单行字号（2026-08-01）

同一列内可混排三档字号，**恒守行格**——小字两枚合占一个字位、大字独占两个字位，故列内字位始终对齐：

| 写法       | 渲染                | 占格    | 用途                                 |
| ---------- | ------------------- | ------- | ------------------------------------ |
| `*文字*`   | 小字（0.70×，可调） | 半格/字 | 单行小注、题署、夹在正文里的小字说明 |
| （无标记） | 正文（1×）          | 一格/字 | 正文                                 |
| `**文字**` | 大字（1.50×，可调） | 两格/字 | 篇内标目、强调                       |

规则：正文与大字自动对齐字位（前有奇数枚小字时补半格）；大字放不下整两格则改排下一列；未闭合标记吃到块尾；星号本身不入正文。与双行夹注（圆括号）互不冲突——夹注是**双行**半字号，此处是**单行**变字号。

## v2 增补：拉丁与数字（2026-08-01）

连续的拉丁字母/数字（含内部 `. - / :` 与单空格）自动**合成一段**排布，不再逐字占格：

- **≤2 字符**（如 `AI`、`75`）：**縦中横**——直立压进一个字位，横向压缩至列宽的 2/3。
- **≥3 字符**（如 `RAG`、`GPT-4.5`）：**转 90° 沿列横排**，按**自然宽度**（逐字符宽度估值）占格并定长——**只压不拉**，字母间不会被撑开；段后正文自动回到字位对齐。
- 字体：**缺省随汉字字体**（同源西文字形最协调）；版式面板可切换为「西文衬线（Georgia／Times）」，用于汉字字体自带西文欠佳时。
- **适用范围**：正文、书名／卷次／著者列、版心（书名·卷次·篇题）——三处共用同一套规则（`engine/latin.ts`）。
