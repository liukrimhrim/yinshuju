**症状**：花鱼尾、线鱼尾与实物差距最大；黑鱼尾大体可接受、白鱼尾次之。

**参考材料**（用户提供，见对话）：

1. 「样式（以单鱼尾为例）」对照图——黑／白／花三种，画在版心列中：象鼻横线在上，鱼尾为扁带，叉口 ∧ 峰朝上，黑尾下另有一道同形细线。花尾为带内留白叶饰 + 边缘曲线。
2. 字体鱼尾字符图——同一套鱼尾做成了**字体字符**（含回纹式、曲边实心式、折线空心式、叶饰式，及上下镜像版）。

**已试过且被否的三条路**（勿重蹈）：

1. 实心块 + 纸色人字饰 → 半叶只露半枚鱼尾时退化成一道斜划痕。
2. 实心 + S 形（如意）曲线叉、无装饰 → 太素，且比例仍是高块。
3. 当前版：扁带（带高 ≈ 列宽 0.44、叉口切穿 86%）+ 象鼻横线 + 回声线；白＝不着墨、线＝三道层叠叉线、花＝每侧四枚同向下垂浅弧 + 每侧两片留白叶。→ 仍不对。

**下次可走的路**（按推荐排序）：

1. **改用现成鱼尾字形/素材**：参考图 2 证明存在含鱼尾字符的字体；找到授权干净的一款（或从公开刻本扫描件描摹），把每种样式做成**一个手工调好的固定 SVG path**，按版心列宽等比缩放贴入。参数化硬凑几何是这三次失败的共因。
2. 若坚持程序化：先把一枚真实鱼尾**描摹成基准 path**，再在其上做参数变体，不要从零推导曲线。
