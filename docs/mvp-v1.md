# 印书局 MVP 规格（v1 首发范围与建造顺序）

定案于「MVP 切分与首发规格」票（2026-07-31）——规划收官文档。**M1 = 三出口全量**：编辑排版、翻页阅读、壁纸/社交图、打印 PDF 一次到位。

## v1 范围

**编辑器**：正文框（markup v1：括号夹注、标点→句读、空行提行、`#` 篇题）+ 元数据表单（书名/卷次/著者/版心简名）+ 参数面板（一等公民 UI）：主题四选 + 七色逐色调 + 行格（名本预设：黄善夫 10×18、殿本 8×17 等 + 自由输入，超历史域 8–15×16–22 软警告）+ 字体 + 纹理强度滑杆 + 印章。文档 localStorage 自动保存，可导入/导出纯文本。

**预览与阅读**：实时单半叶预览、对开视图；阅读模式全屏翻页（点击两缘/滑动，页序右起），分页纯算术。

**导出**：

- 图片：PNG / JPEG（质量参数），**多比例自适应重排**——每档比例重算网格（方形/横屏出对开双半叶；竖长档收窄列数、每列字数守用户设定。2026-07-31 勘误：原文「竖长增行数」系笔误，窄幅减列才是排版正确方向），档位：手机壁纸 9:19.5、3:4、1:1、4:5、对开 2:1、自定义；各社交平台具体像素**开工时现查**，不写死。
- PDF：16×28cm 多页（pdf-lib 逐页嵌图），`#` 篇题自动生成书签目录。
- 浏览器打印（Chrome 矢量 PDF）作增强项。

**字体**：内置三款切片自托管（汇文明朝、朱雀仿宋、TW-Kai 兜底）+ **用户上传 TTF/OTF**（FontFace 显示；导出用 opentype.js 运行时子集内嵌，CFF 字形兼容性开工验证；授权自负提示）。跨字体混排：度量微调（参考字实测缩放）+ 描边配平（vRain 技法）。

**印章**：朱文/白文可选、方/圆/椭圆、篆书（**崇羲篆體**——2026-07-31 授权复核：原定说文篆体实为「个人与系统发展」窄授权，排除；崇羲 CC-BY-ND 整包原样分发+署名，11,596 字，详见印章票后记）、边缘做旧（seed=印文哈希）；**缺字：明确提示缺哪字 + 一键整印退用正文字体**（不混排；TW-Kai 入库后升级为真·退楷）；数量不限，位置=预设槽位（著者列下/卷首/天头侧），自由拖放留 v2。

**文本管线**：简→繁 s2t 开关 + 高危字出现清单提示（人工改字）；管线顺序：句读→s2t（旧字形层 v2）。

## v2 及以后（明确出圈）

句读点选 UI、自带 LLM key 自动句读、旧字形映射层、markup v2 旁线标记集（书名线/圈注/点注/线注）与手动排版控制符、印章自由拖放、字体上传的切片级优化、PWA 离线、竹简/磁青主题。**无后端**是常设假设，分享功能若倒逼再议。

## 建造顺序（里程碑）

- **A 核心闭环**：引擎移植 TS（parse/layout/svg/themes + vitest）→ Svelte 编辑器 + 参数面板 + 预览。
- **B 导出全家桶**：多比例重排、PNG/JPEG、PDF 多页书签；**Safari 实测**（SVG-as-image 字体 → 必要时 text→path 兜底）。
- **C 印章**：硬前置=说文篆体授权两说复核 → 生成器 + 缺字 UX。
- **D 收尾发布**：阅读模式、简繁、上传字体、Actions 部署上线；**并入 A 的显式后置项**：TW-Kai 兜底字体入切片管线 + fetch 校验和、篇题自动入版心开关（themes-v1 可选项）；**并入 B 的显式后置项**：发布前 Safari 实测（SVG-as-image 内嵌字体；翻车则启用 text→path 兜底）、浏览器打印矢量 PDF 增强项。

A/B 不被 C 的授权复核阻塞。

## 验收标准

四主题各对标其样张（做旧对标《香乘》纹理）；夹注在手机宽度可读；导出图与预览像素级一致；四样张原文各排一页作为回归样例（docs/markup-v1.md 已含三则）。
