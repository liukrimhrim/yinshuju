## 做旧纹理规范

- **纯程序化 SVG 滤镜，不引入位图素材**——零授权负担、导出已验证（样张验证票）、seed 取内容哈希（同文同貌、可复现）。
- 四层：纸张斑驳（低频 fractalNoise 着色）、细纸纹（高频噪声）、墨迹侵蚀（位移+噪声挖蚀）、边框残损（大尺度位移+重挖蚀）。原型 `proto/render-route` 的 filter 参数为基线。
- **强度滑杆**（0–1）映射位移 scale 与挖蚀阈值；默认 0.6。
- **小字易读性守则**：夹注字号的侵蚀位移取正文的 60%、挖蚀阈值降一档；验收标准=对标《香乘》样张且夹注在手机宽度可读。
- 纹理层可单独开关（做旧主题关掉纹理=素色仿古）。

## 版心鱼尾（2026-08-01）

按版式规范票 §1/§8 参数化，独立于主题、用户可调：

- **数量**：单鱼尾（历代占比最高）／双鱼尾。
- **样式**（考据：_轮廓填实者黑、只描外廓者白、若干线条组成者线、分叉处为曲线或内有图案者花_）：黑鱼尾（实心直叉）／白鱼尾（空心直叉）／线鱼尾（外廓+两道内嵌叉线）／花鱼尾（实心 S 形如意曲线叉）。注：半叶只露半枚鱼尾，故花鱼尾不用内部纹饰（会退化成斜划痕），装饰性全落在叉的轮廓。
- **双尾朝向**：对鱼尾（尾尖相向，下尾镜像）／顺鱼尾（同向）。
- 单尾本自动附版心 3/4 处横细线（宋至清常见变体）；页码位置随之：单尾在横线下、双尾在下鱼尾下。

## 版心内容

三段制（版式规范票）：鱼尾间 = 简名 + 卷次 + 页码；**新增可选开关：当前篇题自动入版心**（vRain 的章回替换机制，从 `#` 篇题取值，随页更新）。
