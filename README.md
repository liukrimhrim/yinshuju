# 印书局

把一段文字，印成一叶古书。

粘一段白话或古文进去，出来是竖排、界行、版心鱼尾、双行夹注、句读圈点的线装书版面——可导图片、PDF，也可直接打印。

**在线使用：<https://liukrimhrim.github.io/yinshuju/>**（纯前端，文字不出浏览器）

---

## 三步上手

1. **正文**页贴文字，填书名／卷次／著者。零标记就能出版面——现代标点会自动变成古书的圈点。
2. **版式**页调行格、主题、鱼尾、字体、留白。
3. **导出**页选比例，出图片／PDF／打印。

## 输入格式

只有两条要学：**空行**分段，**`#`** 标篇题。其余按需要加。

| 写法                   | 效果                                                       |
| ---------------------- | ---------------------------------------------------------- |
| 空行                   | 提行（另起一列）；多空一行就多空一列                       |
| `# 捭闔第一`           | 篇题，自成一列、低二格                                     |
| `> 唐李白撰`           | 题署，自成一列、低格对齐；可多次使用，几位作者能并列同一叶 |
| `---`                  | 分叶，其后另起一叶                                         |
| `（考察审定）`         | 双行小字夹注（半角 `()` 也认）                             |
| `。！？` `，、；：`    | 自动转句读圈点，画在字的右下角、不占字位                   |
| `*小*`　`**大**`       | 行内字号（倍率可调）                                       |
| `《书名》`　`［人名］` | 书名线／专名线，画在字右侧、不占字位                       |
| `｛…｝`　`＜…＞`       | **圈点关键词句**：密圈／密点，朱笔画在字右侧、不占字位     |
| `【…】`                | **眉批**：写在天头，锚在标记所在那一列；不占正文字位       |
| `[2]`　`[2,0]`         | 段首留白：天地各留 2 字位／只留天头                        |
| 空格                   | 半角＝半字位，全角「　」＝一字位                           |

英文与数字自动成段：三字符以内直立压进一个字位（`RAG`、`AI`），更长的转 90° 沿列横排。

完整规则见 [docs/markup-v1.md](docs/markup-v1.md)。

## 版面

- **四套主题**：朱丝栏、清雅素白、仿古做旧、朱印本；七种颜色逐色可调。
- **行格**：4–20 行 × 8–27 字，附四种实物预设（黄善夫本十行十八字等）。
- **版心**：鱼尾一尾／双尾（黑／白／花／线，对尾／顺尾）、简名卷次、篇题可自动入版心、叶码可设起始与字形。一版两半叶共用同一版心与叶码——右半叶得版心右半、左半叶得左半，正是雕版对折的样子。
- **印章**：朱文／白文，方／圆／椭圆，篆书取崇羲篆體；缺字明确提示，可一键整印退用正文字体。
- **评点**：`｛…｝`／`＜…＞` 圈点关键词句（朱笔密圈／密点），`【…】` 写眉批入天头——眉批用行书或草书，字号、字体、显隐可调；繁体缺字落全字库正楷，要整篇繁体行书可在本机字体库添加自备字体。
- **简→繁**：正文与书名著者版心一并转换（opencc）。一简多繁的高危字会提示人工核对。
- 天头地脚留白、字距疏密（横纵分开）、书名／篇题／著者字号，都有滑杆。
- **预览**：逐面翻，可切「对开」看整叶；「阅读」进全屏，右起左翻，键盘／触屏滑动都行。

## 导出

- **图片**：PNG／JPEG，×2–×4 倍率；比例含原开本 16:28、手机壁纸 9:19.5、竖幅 3:4／4:5、方形对开 1:1、横幅对开 2:1，也可自定义。方形与横幅自动排成对开整叶。
- **批量**：一次导出全部版面，打包成一个 zip（对开时一版一张）。
- **PDF**：固定 16×28cm 开本多页，带篇题书签。
- **打印**：`@page 16cm 28cm`，Chrome 下出矢量文字。

导出的图片会把用到的字**子集化内嵌**，换台机器看也不掉字。

### 本机字体库

「版式」页可以**添加本机字体**（TTF/OTF，可多款）。字体存在你自己浏览器的 IndexedDB 里，刷新、重开都在，在字体下拉里与内置字体并列——但**不进仓库、不随本站分发**，导出时才在本地子集化内嵌进图片。

授权只许个人使用、不得对外提供字体文件的好字，走这条路正合适。三款推荐：

| 字体                                | 何时用                                                       | 取得                                                                         | 授权要点                                                                                        |
| ----------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |

## 本地开发

```
npm install
npm run fonts     # 拉字体源文件并切片到 public/fonts（需 uv；只需跑一次）
npm run dev
```

其余脚本：`npm run check`（svelte-check）、`npm test`（vitest）、`npm run build`、`npm run format`。

推 main 即由 GitHub Actions 跑检查并部署到 Pages。

**技术栈**：Svelte 5 + Vite + TypeScript。版面由自研布局引擎算成逐字坐标表，再渲染成 SVG——屏幕、图片、PDF 三个出口共用同一张坐标表，所见即所得。引擎（`src/lib/engine/`）是纯函数，不依赖框架。
